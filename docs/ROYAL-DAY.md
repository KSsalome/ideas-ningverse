# 皇家午光：11:00–14:00

依 `Asia/Taipei` 自動切換。七座島共享蔚藍天空、柔和白雲、高位暖白日照與極淡遠景霧；只有主島換成中世紀皇家城堡。其他島保留原來建築、地形、道路、橋樑、植栽種類、配置與作品入口。

## 全域日間

- 沿用單張最長邊 768px 的背景畫布，為所有島繪製相同的藍天、6 組慢速白雲與高位太陽。沒有日間星光、月亮或夜間光暈。
- 重用原本的環境光、半球光、方向光、陰影與反射，不新增燈光或後製 pass。方向光提高至高位陽光，使用暖白日照，保留米白石材、深色玻璃、紅水晶、古銅金屬與自然葉色。
- 降低原有戶外燈光池至日間基準的約 45%，燈帶與裝飾光也降低；水晶保留內部微光，科技燈帶保持辨識度，酒吧室內仍使用原有暖光規則。
- 日間減少已標記的光暈、礦山薄霧及光池透明度。全域霧遠點延至 430，近點延至 205，保留遠景層次與清楚的入口／道路。
- 使用共用環境狀態的日間、夜間、深夜三組權重，以 8 秒過渡。11:00 漸入全域午光，14:00 漸出，其他時段維持原本規則。

## 主島皇家城堡與庭園

- 保留原有城堡幾何、中央主塔、副塔、城牆、拱門、石階與三層量體。主島專用材質切為奶油白石灰岩、暖灰石材、藍灰石板屋頂、香檳金裝飾及皇家深藍旗幟；不會改到其他島的旗幟或屋頂。
- 拱窗降低粗糙度並開啟適度透明度，搭配新增的胡桃木框與金屬分格。各時段的材質切換可以復原，不替換全世界的共用材質。
- 中央原位置 (0,0,5) 使用自然色清水噴泉：簡化石盆、雙層水盤、6 道柔和水流與微量水紋；不使用霓虹、水晶能量或新增光源。減少動態效果時停止水紋動畫。
- 新增對稱皇家盾徽、兩座木長椅、兩座完整石雕、兩座花盆。庭園包含圓形樹冠、細長柏樹、低灌木、對稱花圃、少量常春藤與攀爬玫瑰；花卉使用白、淡粉、淡黃與少量紫色。
- 主島仍只保存一組當前植栽，在時段邊界淡出、釋放，再淡入下一組。步道、橋樑接點與互動入口保持原樣。
