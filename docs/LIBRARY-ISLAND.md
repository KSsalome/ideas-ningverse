# 圖書島：英倫復古 × 新古典 × 魔法圖書館

以島主 2026-10-28 提供的國家圖書館參考為方向，使用即時 Low Poly 幾何，重建外觀與室內。圖書島的位置 `(-29,-43)`、圓形平台半徑 `16 × 15`、高度 `3.2`、橋樑端點與藏書 ID 不變，外部入口仍在原有建築前方。

## 外觀與庭園

- 寬 15.2、深 9.6 的對稱長方形館舍，米白石灰岩、淺灰石材、古銅裝飾、深胡桃木門框與黃銅把手。圓拱窗及真正鏤空的石牆使用重複幾何，與城堡尖塔分開。
- 墨綠低矮板岩屋頂、中央玻璃採光穹頂、屋面採光開口、薄金屬接縫、柱列及三角山牆；移除原本雙尖塔與屋頂星象儀。遠景採相同寬闊輪廓。
- 寬石階對齊原本靠近互動位置。角色在石階區使用平滑步行高度，避免穿過台階。
- 淺灰米色鋪磚、少量深灰飾磚；黑色鍛鐵與古銅扶手在橋口留出通道。維多利亞燈柱具有四面玻璃、黑鐵框、古銅細節及暖黃核心。
- 保留少量酒紅旗幟，加入長椅、幾何石雕、修剪綠植與三張漂浮書頁。戶外四盞有限距離暖色點光源共用照明額度，遠離圖書島即停用。
- 後台外觀預覽、外觀名稱、選位範圍與 MCP 說明同步。建築代表色僅用於實體招牌的小型嵌飾，主配色維持指定風格。

## 室內與藏書

- 挑高長廊、深藍星空弧形拱頂、少量幾何古典壁畫、奶油白石牆、深綠壁板與胡桃木線腳。
- 上下兩層深棕實木書架、兩側樓梯、二樓環形走廊與欄杆；中央深紅長地毯、深木閱讀桌、皮革椅、黃銅桌燈、古典地球儀與低亮度吊燈。
- 樓梯、走廊與家具使用同一份位置與行走規則。點地面尋路會繞過桌椅，沿樓梯上樓；鍵盤／搖桿也可直接行走。樓層高度保存於場景快照，舊版僅有 X／Z 的快照仍從一樓安全恢復。
- 每個書架容納 30 本書；每一段長廊上下左右合計 120 本，超出後延長長廊。書籍的 ID、標題、顏色、內容與點選閱讀流程沿用，沒有填入示範藏書或改寫正式資料。
- 原生模式每 32 本書共用一張 256 × 2048 書背圖集，合併書本可見幾何；獨立的隱形點選區維持每本書精準對應。相容模式仍用實際標題的 DOM 書背。
- 藏書與筆記清單、私人內容權限、新增／刪除／編輯、返回群島與人物配件沿用既有功能。

## 驗證與限制

37 項核心檢查涵蓋六時段外觀、石牆／綠屋頂／穹頂／門把、路燈、未變更的入口、選位邊界、兩側樓梯與環形走廊的往返、桌椅碰撞、雙層書籍座標、點選 ID、圖集數量與有限幾何。型別檢查通過。屋面相容模式層次修正後，已再跑圖書館外觀檢查。

其他六座島、全部橋樑、美術館與工廠室內的材質、幾何及模型變換雜湊均與修改前一致。預設圖書島外觀約 5.8 萬三角形；室內建築約 1.7 萬三角形，使用靜態合併與重複材質。這些數字為幾何規模，並非手機幀率。

預覽環境沒有 WebGL，採 SVG 相容模式。原生透明玻璃、法線貼圖、GPU 光暈／陰影及手機實機幀率仍待實際裝置確認；不以相容模式截圖宣稱實測光影或流暢度。


瀏覽器已驗證正式圖書館的空藏書畫面、書目清單，以及隔離的 65 本測試書架：一樓與二樓書背點選會回傳正確書籍 ID，角色可沿樓梯上樓並回到一樓。390 × 844 直式 iframe 的 body 寬與 scrollWidth 皆為 390，清單能開啟，沒有橫向溢出。桌面外觀確認為寬闊低屋頂館舍，修正 SVG 屋面三角排序造成的遮擋。透明玻璃及燈光核心不投射不透明陰影。

預覽截圖：`library-island-neoclassical-preview.jpg`、`library-reading-hall-preview.jpg`，皆為實際 SVG 相容模式，非原生 GPU 光影。65 本測試書、QA 路由、直式 iframe 與本機臨時 secret 已在打包前移除；正式藏書與玩家資料未修改。


## 室內封閉與鏡頭邊界（2026-10-28）

圖書館前後端皆以延伸至拱頂的封閉牆面收口，入口保留館內木門與壁板。鏡頭起點已移到館內，室內軌道縮放限制為近距離，並逐幀限制鏡頭與近裁切面於牆內。追蹤焦點跟隨角色與樓層，二樓不會把鏡頭降到樓板內；閱讀桌、柱列與環形走廊使用簡單盒體阻擋鏡頭，避免以全模型高成本射線求交。重設只調整當前角色附近的室內視角，並清除旋轉慣性。

新增測試涵蓋兩館原生／SVG 模型的全向封閉、長短長廊、極端縮放與角度、390 × 844 直式／桌面／寬螢幕近裁切面、樓層與重設。合計 39 項核心測試通過。戶外玩家縮放、圖書島外觀與內容資料未變更。
