# 群島夜色與未來王城

> 後續哥德深夜更新已接續 23:00–04:00 的共用夜色，23:00 不再退出夜間環境。最新規則與驗證見 [GOTHIC-NIGHT.md](GOTHIC-NIGHT.md)。下述「其他時段」與「夜色限於 17:00–23:00」為科技版本當時的範圍紀錄。

17:00–23:00 以 `Asia/Taipei` 自動判定：七島共享夜空、月光、星點、薄雲與霧色，只有主島城堡更換為科技材質與主題裝飾。正式網站沒有測試時鐘或手動換景按鈕。其他時段沿用原先的主島氛圍範圍。

主島保留城堡的所有幾何、層次、位置和入口。外牆以銀灰、深藍與黑色金屬表面切換，淡化原本磚紋；屋頂與尖塔新增青色、粉紫色細線，搭配全息旗幟、兩個投影裝置、科技環及中央藍紫色能量噴泉。植物使用主島專用的夜間庭園。

圖書島、神殿、科技島、礦山及工業酒吧的建築材質底色、形狀和內容 ID 不變。只調整原有窗光、路燈、水晶／霓虹發光強度與植栽明暗。月光為低彩度藍灰，暖窗、自然花園及象牙白石材仍保留自己的顏色；不增加全畫面色彩濾鏡或全域泛光強度。既有室內採光與封閉相機機制保持。

## 切換與效能

- 每秒檢查一次臺北時段，以 8 秒插值切換全域夜色、城堡表面、主島照明與裝飾。主島植栽先淡出、釋放，再淡入下一組，只保留目前一組植物。
- 攝影機、縮放、玩家位置、行走路線、橋樑與作品入口不重建。
- 重用戶外既有環境光、半球光、方向光、點光與聚光池；所有新增裝置都不使用新的即時光源。
- 天空為最長邊 768px 的單張 2D 畫布，48 顆星、6 層薄雲，約每 140ms 更新，位於透明 3D 畫面後方。所有島共享同一層天空，沒有其他島排除遮罩。
- 科技裝飾合併後原生 16 個網格、6,108 三角面；相容模式 13 個網格、492 三角面。只保留少量轉動與浮動，遵守減少動態效果。
- 同時補齊午後主島的古銅齒輪、鐘面、管線、玻璃溫室、遮棚與戶外小桌椅；原生 13 個網格、5,764 三角面，科技時段隱藏。其他島午後設定不變。
- 夜間強度由固定日間基準計算；重新挑選附近燈光後不累乘，返回日間可完整恢復。
