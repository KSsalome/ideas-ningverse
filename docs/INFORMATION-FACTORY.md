# 資訊工廠 · 工業酒吧

以使用者提供的工業酒吧參考圖為方向，使用可步行的原生 Low Poly 幾何，取代資訊島原本的白色斜頂工廠及高挑魔法展廳。

## 外觀與島嶼

- 方正寬體、低樓層與平屋頂；深灰混凝土、黑鐵板、舊金屬、少量鏽蝕與古銅管線。
- 深木玻璃入口、實體「INFORMATION FACTORY」及 BAR 招牌、黑鐵罩燈、暖色櫥窗與瓶架。
- 屋頂有低矮設備、資訊儲罐、兩根煙囪與外露管線，沒有城堡尖塔。
- 圓形平台保留原位置 (-82, 43)、半徑 14 與高度 1.6。以暗岩底座、吊掛斜撐、黑鐵欄杆、少量植栽延續懸空感。
- 連向資訊島的橋樑改用深色鋼板與鐵欄杆；橋樑位置、寬度、路線與既有步行功能不變。
- 外觀、遠景、後台預覽、外觀選單、選位範圍與 MCP 說明同步更新。

## 可探索的室內

- 深木吧台、黑鐵框架、古銅包邊與腳踏、五張皮革高腳椅。
- 五層整面酒瓶牆；原生 145 瓶、SVG 相容模式 95 瓶，以簡單六角圓柱與少量標籤製作，並合併靜態幾何。
- 深棕皮革卡座、木桌、散座高桌、黑鐵網、地圖、書本與資料終端。
- 交錯凸起菱紋的防滑鋼板地坪、黑色天花、I 型鋼梁、外露管線、工業吊燈與壁燈。沒有新增大量粒子。
- 原有四筆資訊與 ID 保留，展板、清單、閱讀、後台管理與新增內容仍沿用原有資料流程；不替使用者填入新的正式個人資料。
- 展板依數量延伸空間。家具座標共用於角色碰撞、點地面尋路與鏡頭碰撞；支援非格點起步，避免四捨五入卡在家具邊緣。
- 室內全封閉，玻璃有實心暖色背景，鏡頭與近裁切面受房間及家具限制。

## 光線與效能

- 室內一直維持暖黃光。臺北 06:00–17:00 稍提高柔和環境光；17:00–06:00 降低環境光、略強調局部燈，保留昏暖酒吧氛圍。每秒檢查一次系統時間，重用同一組光源。
- 原生室內最多六盞無陰影局部燈；室外最多六盞暖燈依距離啟用及重新分配。燈具與玻璃不投射實心陰影。
- 金屬、木材及水泥使用重複材質與小尺寸紋理；全站曝光、選擇性暈光與其他島嶼材質不變。
- 維持 SVG 相容模式與 reduced-motion；手機使用既有搖桿、觸控環顧及資訊清單。

## 驗證

49 項核心測試通過，包含原有圖書館日夜天空、防穿模、所有島嶼通道，以及工業酒吧新增的材質、入口、家具尋路、封閉房間、鏡頭邊界和幾何規模檢查。

六座其他島及美術館、圖書館室內，原生與相容模式共 16 組模型變換／幾何／材質雜湊與修改前一致。瀏覽器確認展板閱讀、資訊清單、角色行走、外觀及 390 × 844 直式畫面，寬度和 scrollWidth 都為 390。

本環境的瀏覽器停用 WebGL，截圖為 SVG 相容模式。未宣稱已實測手機 GPU 幀率、原生材質反射或原生光暈效果。

## 英文招牌、舊黑鐵與壓紋鋼板更新

- 內外實體招牌、室內標題、地圖名稱與靠近提示統一顯示 `INFORMATION FACTORY`。個人資訊記錄、ID 與原有文字不改寫；搜尋支援英文顯示名及原名稱。
- 舊黑鐵外牆與內牆使用 256 × 256 的色彩、粗糙度、法線紋理，加入金屬拉絲、細刮痕、局部氧化、接縫與少量鉚釘。相容模式用深黑鐵配色及少量刮痕幾何。
- 室內地板依使用者照片改為交錯凸起壓紋的防滑鋼板。原生以 .8 世界單位的重複紋理／法線呈現金屬反光；相容模式使用一個合併網格，約 3,000 個雙切面壓紋，沒有每枚壓紋的獨立 draw call。
- 四個展示框增加細暖光邊與低透明度外暈。光線限制在框外，保留中央圖片與文字。點選、鍵盤焦點、原始內容 ID 與閱讀流程不變。
- 新增六盞壁燈、兩盞吊燈；新增 `OPEN LATE`、`STORIES`、`HIDDEN BAR` 霓虹字，搭配暖橘、低飽和青綠與柔紅。主招牌也改為發光英文。
- 所有霓虹使用相同的低複雜度幾何字體，原生與相容模式共用。選擇性光暈只接收燈芯、文字與展框光邊；牆面、地板及內容不進入暈光。未增加全站曝光或全站 bloom 強度。
- 預設室內低於 50,000 三角形及 90 個靜態架構網格；最多六盞有距離上限、無陰影的局部燈。這是幾何與光源預算，並非手機幀率。
- 49 項測試通過；瀏覽器已確認英文標題、展框閱讀、霓虹、鋼板地坪、地圖名稱及 390 × 844 無水平溢出。WebGL 在此環境不可用，原生反光與光暈尚未進行實機驗證。


## 外掛樓梯與暖黃色外景照明

- 東西兩側新增四段外露黑鐵維修梯，分為約 .45、3.12、6.2 高度，搭配中繼平台、上層平台與後側高架維修走道。
- 階梯具有獨立踏板、斜向梯樑、護欄、立柱及支撐；原入口台階兩旁增加外層梯頰。
- 新增 22 組暖黃護罩燈，逐一安裝在踏板外側、平台立柱與入口梯頰。每組都記錄實際承載的踏板或平台高度，避免懸空。
- 每個燈具具有黃色燈芯、黑鐵燈罩及低透明度暖色小光暈。原生外景最多六盞有距離上限、無陰影的局部燈，按觀察目標的水平位置及高度重用光源；未增加全站曝光。
- 四段樓梯與後側走道為外觀維修結構。地面導航保留支架占用範圍，避免穿過模型；原入口、橋樑與外圈繞行通道仍可通行。
- 外觀遠景、後台預覽、點選範圍與建築選位包絡同步更新。室內、其他島嶼及正式內容不改動。
- 樓梯與新燈具約增加 12,000 個原生三角形；相容模式約 9,400 個。遠景使用稀疏燈具。這是幾何規模，並非手機幀率。
