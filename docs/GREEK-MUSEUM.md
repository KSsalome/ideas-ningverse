# 光影美術館：完整希臘神殿與神話花園

美術島保留中心 `(29, -43)`、半徑 `15`、高度 `2.4`、原有橋端點及美術館入口 `(29, -35.2)`。神殿採完整石材三角屋頂、前後六柱列柱、兩側迴廊、簡化科林斯柱頭、寬石階與金色大門；沒有城堡尖塔或遺跡元素。

外觀固定使用米白、象牙白與香檳金；島嶼仍隨臺北時間使用全站六時段的天空及主光。地面有大理石磚縫、金色圓環與回紋。花園含白／淡粉玫瑰、柏樹、藤蔓、對稱女神石雕、圓形噴泉、小列柱涼亭、拱廊及觀景座椅。四盞無陰影、有限距離的局部燈重用在最近燈具；十個原生／四個相容模式的小花瓣與金點支援減少動態效果設定。沒有提高全站曝光或泛光。

室內為完整封閉的中央挑高大廳，樓面在 `0 / 5.4 / 10.8`，兩層環形廊道以四段中央折返樓梯連接。樓梯具有真實階面、支撐、扶手及中繼平台。半單位路網使用連續高度檢查，避免跳層、跌入中庭、穿過展示櫃或在樓梯半途失去路線。角色位置保存包含 `y`；更新作品後仍保留合法的當前樓層。

各樓層不設樓層文字、名稱或大型指示牌。攝影層使用相機、底片、三腳架及柔光箱；Cosplay 層使用服裝模特兒玻璃櫃、假髮架與道具台；繪圖層使用淺胡桃木地板、空白畫架、素描展示紙、調色盤、畫筆及石膏雕像。這些是場景裝飾，不會寫成正式作品。

## 作品與管理

`artworkSchema.gallerySection` 新增 `auto / photography / cosplay / drawing`，舊紀錄自動使用 `auto`。繪畫預設三樓，攝影與影片預設一樓；所有媒材都能在後台指定展區。既有作品 ID、媒材、檔案、文字、隱私與更新衝突保護保留。專案內作品仍依原專案分類收進展區，不建立複本。

每層至少六個不同大小的互動展框，作品增加後自動延伸展廊。既有作品開啟原詳細閱讀介面；空框讓島主建立該展區的草稿，保存前不新增正式資料。訪客點空框只提示正在等待作品。作品清單與刪除流程保留。

室內有三盞中庭暖光及兩盞重用的柔和展品聚光燈，不額外投射陰影。只有燈芯參與原有選擇性泛光。側牆、前後牆、地板與天花板均封閉；鏡頭與近裁切面保留各樓層的邊界限制。相容模式只顯示目前樓層的展框，避免 SVG 畫家排序把上層展框畫穿樓板。

## 原始碼

- `lib/museum-style.ts`：配色、入口高度、外部碰撞與作品分區。
- `lib/museum-layout.ts`：三層樓面、展示家具範圍、展框位置與樓梯路線。
- `app/museum-kit.js`：重用石材、簡化科林斯柱頭、雕像、白石欄杆、燈具與植栽。
- `app/museum-island-art.js`：神殿、圓形島台、花園及遠景模型。
- `app/museum-interior-art.js`：三層展廊、中央樓梯與辨識各展區的裝飾。
- `app/museum-exhibits.js`：資料對應的可點選展框。
- `app/museum-scene.js`：人物行走、作品點選、鏡頭保護與局部聚光燈。

## 驗證

核心與美術館測試共 54 項。檢查舊作品的分區預設、指定 Cosplay 與輸入驗證；逐段往返三層並在樓梯非格點恢復行走；六個時段的完整屋頂、入口、橋樑及外部碰撞；各層道具與展框射線點選；所有樓層及兩個中繼平台的鏡頭與近裁切面邊界。

其他六座島、圖書館與工廠室內，原生／相容兩種模式共 16 組模型、材質及變換雜湊與修改前相同。預設原生美術館外景低於 7 萬三角形；室內含 18 個展框低於 5.5 萬、150 個網格。建築與道具依材質合併；石材紋理只有一張 128 × 128 程序紋理，無新外部圖片或套件。
