## 隔離方式

- `lib/home-atmosphere.ts` 集中定義主島六種配色與造景。時間沿用既有 `phaseAt()`，以臺北時區判定，跨午夜也正確。
- 其他島、共同橋樑及全域燈光固定使用既有 `industrial` 基準設定。這次沒有修改其他島模型檔案、材質檔案、位置、作品資料或互動入口。
- 共用地圖不能直接切換 `Scene.background`、全域曝光或環境光，否則會連帶改變所有島。主島改用一層低解析度 2D 動態天空，由主島的投影範圍柔和遮罩；其他島的平台／建築周圍另有排除遮罩。攝影機轉往其他島時停用這層天空。這層在 3D 物件後方，不會覆蓋建築或角色。
- 3D 照明以主島專用材質的 shader uniform 調整，不新增全域燈，也不改變其他島接收的光線、環境反射、曝光或霧色。保留原有陰影。相容模式以頂點色模擬局部光感，褐色屋頂與石材的底色仍保留。
- 保留主島四個有範圍的路燈光源，距離不超過 6.4、強度不超過 24、不增加陰影光源。夜間可偏青紫／暖紅，其他燈仍保持暖黃。
- 圖書館、工廠等既有室內的獨立採光時間、相機限制及展品功能沒有改動。

## 切換與效能

- 每秒確認一次臺北時段；回到分頁時會立即依當下時間更新。時段改變只更新主島材質與目前植栽，不重新建立整個群島、攝影機、角色或互動入口。
- 玩家縮放、視角、行走位置及路徑保留。不新增自動縮放、不新增公開換景按鈕。
- 只保存目前一組植栽；切換時釋放上一組幾何與材質。各組使用共用幾何並合併靜態網格。
- 原生植栽約 9,458–15,324 三角面、9–23 網格；相容模式約 3,526–5,234 三角面。最多 8 個原生／4 個相容模式微光，不新增粒子系統或 3D 後製 pass。
- 天空緩衝區最長邊 768px，投影遮罩最多 64 × 128，僅相機或尺寸改變時重算；一般天空動畫約每 140ms 更新。遵守減少動態效果偏好。

## 驗證與畫面

- 六時段含 00:00、04:00、08:00、11:00、14:00、17:00、23:00 邊界及不同來源時區的相同時刻。

- 320px、390px 與 1363px 畫面沒有水平溢出。預覽環境使用 SVG 相容模式，不能據此宣稱已測得手機 WebGL 幀率或原生 GPU 光影。
