## 共用深夜環境

- 夜色由 17:00 延續至 04:00，23:00 從科技夜色平滑轉入深夜，不會閃回日間。全域方向光切為冷白月光色，環境光、半球光、反射與輪廓光再降低。

- 原生低空雲霧重用原本的雲層；遠景霧僅輕微加深，近距離步道、入口與操作仍清楚。2D 天空層的淡霧位於所有模型後方，不覆蓋角色或 UI。
- 共用畫布最長邊 768px，最多 48 個既有星點；深夜將其中 16 個淡出，另 32 個降低亮度與閃爍速度。6 層薄雲慢速移動，月亮保留柔和光暈。減少動態效果時停用漂移與閃爍。
- 其他島的植物保留原模型、配置與材質物件，只將亮度由日間基準降低至約 70%。圖書館、神殿、科技都市、礦山及工業酒吧的建築材質底色、粗糙度、金屬度、幾何與 ID 不變。
- 原有暖窗、路燈、紅水晶、淡紫塔羅光及霓虹保留各自色彩。深夜以更低的環境亮度提高局部光源對比，不增加照亮整座島的彩色泛光。
