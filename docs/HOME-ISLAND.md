# 主島：石灰岩層疊城堡

2026-10-27 依島主提供的聖歇米爾山配色照片與層疊城牆參考重建。這輪範圍僅主島；網站保持私人。

## 配色與材質

| 元素 | 實作 |
| --- | --- |
| 全部主島屋頂、塔頂、日記小屋與遠景替身 | 深咖啡 `#39291f`，配棕色瓦縫與屋脊；六時段不變回藍色 |
| 城堡牆面 | 暗米白 `#bfb298` 石灰岩磚，砂漿縫、石塊色差與細顆粒表面 |
| 基座與城牆 | 暖灰褐 `#95856d`、`#92836c`，階層分明的牆腳、壓頂與垛口 |
| 主島地面 | 暖灰米色 `#a99b82` 交錯砌磚，全島步行面與城內平台皆鋪磚 |
| 旗幟 | 沿用深酒紅金邊 |
| 綠植 | 橄欖綠森林、低花圃、內庭小樹與攀牆常春藤 |
| 路燈 | 暖黃燈芯、局部光暈與地面光池；有限距離點光照亮附近磚面 |

石材、屋瓦與地磚使用本機程式產生的 256×256 可重複色彩／法線／粗糙度貼圖。UV 依世界尺寸配置，牆面放大不會把單塊磚拉長；不依賴外部付費素材或第三方貼圖服務。SVG 相容模式使用交錯石磚幾何及多層淡色圓形光池。

## 城堡層次

- 下層外庭：平台高度 +2.6，外圈城牆、垛口、四座瞭望塔、雙塔城門與逐階石梯。
- 內庭平台：高度 +4.6，較小的城牆輪廓，保留中央井與內庭小樹。
- 上層主堡：四棟不同高度的翼樓圍繞庭院，後側主殿、鐘塔與兩座高塔形成逐級升高的輪廓。
- 私藏日記小屋的位置仍為 (-3, -6.2)，私人平台維持原高度，原有城門、日記與城堡互動入口沿用。
- 上層建築均留在原本不開放進入的城堡範圍；主島邊界、橋頭高度、橋樑路線、作品內容及權限資料沒有修改。

路燈共有 12 組。WebGL 使用最多 4 盞可重用的近距離點光，依鏡頭目標選擇最近燈位；燈光距離上限 6.4，夜間強度上限 24，白天較弱。每一盞仍保留可見燈芯與獨立的地面光池。遠離主島時停用實際點光，避免照明範圍或運算成本無限制增加。

## 維護與驗證

- `app/home-island-art.js`：主島模型、層疊城堡、鋪磚、植栽、路燈與遠景替身。
- `app/home-materials.js`：主島固定配色、可重複石材貼圖與世界尺寸 UV。
- `app/world-art.js`：主島專屬模型接入與其他六島維持既有模型。
- `app/art-kit.js`：新增可選的局部 palette 參數，採複製合併，不修改全域六時段設定。
- `app/island-scene.js`：完整釋放法線／粗糙度等材質貼圖；SVG 切島直接定位鏡頭，避免大量磚面下的緩動延遲，縮放值仍由玩家決定。

25 項核心檢查包含六時段主島固定配色、城堡層次、磚面貼圖／UV、每盞燈的發光核心及有限距離點光。另以修改前提交 `124078e13708e531296d0a612dd57876bcb57460` 的模型比對科技、礦作、美術、圖書、社交、資訊六島：材質類型／顏色、位置／旋轉／尺寸與全部三角形座標雜湊一致。

預覽瀏覽器不提供 WebGL。相容模式可確認城堡輪廓、棕色屋頂、石磚鋪面、旗幟與植栽；GPU 法線貼圖、局部點光和實機手機效能仍未實測。
