# 星軌群島美術實作

依 2026-10-27 使用者提供的四張參考圖重建。圖 1、2 為主要方向：象牙白建築、深酒紅旗幟、黃金星軌、暖色燈籠、藍色魔法光與圓潤的小旅人。圖 3、4 補充科技高樓、全息介面、暗紅水晶與礦山吊架。

| 科技島 | 黑色玻璃高樓、四色窗光、分層霓虹招牌、濕柏油反射、道路高桿燈、訊號摩天樓與遊戲基地，詳見 `TECHNOLOGY-ISLAND.md` |
| 手作礦島 | 暗黑哥德 × 蒸汽奇幻：非對稱深灰岩層、五種緋紅晶體、三座差異木礦洞與礦車／鐵軌、六張牌環繞紫黑塔羅尖塔、古銅月冠／符文、酒紅旗幟、薄霧與暖燈，詳見 `MINE-ISLAND.md` |

| 旅人 | 圓頭、短外套、領口、袖口與靴子；沿用既有膚色、髮色、配件與穿戴紀錄 |

模型使用即時 3D 幾何與材質。2026-10-27 依島主實機過曝截圖重新校準：六時段曝光降至 0.8–0.9，降低環境及補光；石材提高粗糙度並移除金屬性，室內地板使用不透明霧面石材。移除桌面鏡面反射與遠景模糊，以保留近看細節。

輝光改為獨立遮罩通道，僅收錄明確標記的小型燈芯、星光、細光條與科技島亮窗；牆體、未亮玻璃、上傳作品、天空、雲霧均不參與。半解析度光暈在合成前限制最大值與增益；遮罩以 try/finally 還原材質、背景、霧及可見性，隱形點擊區仍保持隱形。

所有旗幟使用固定 `#4b1b2b` 深酒紅布料，不隨六時段變成藍色；旗幟具有摺面幾何、金邊、掛桿及墜飾。屋頂、地毯與介面保留既有深藍配色。

共用建築補上立體基座、層疊簷口、石砌接縫、轉角砌石、側／背窗。尖拱窗使用中空擠出石框，玻璃退後超過 0.15 單位，增加窗台、窗櫺與門環。屋頂增加瓦片分層、金屬接縫及屋脊；尖塔增加石帶與肋條。高樓具四面窗格、樓板、陽台、屋頂退縮與設備；保留專案色與施工進度。礦洞增加岩塊與支撐細節，遊戲館增加金屬百葉，工廠增加窗格與管箍。室內加入柱腳／柱頭／柱槽、下牆嵌板、石材分層和天花格框。

光影採斜向暖色主光、較弱冷色輪廓光、PBR 材質及方向光陰影；室內另有三盞有限距離暖燈。靜態合併保留材質、繪圖層次與投影／受影屬性，避免原本不投影的天花板在合併後遮住室內照明。

無 WebGL 時使用較簡化的相容繪圖。遠島保留輪廓，鏡頭靠近的島嶼使用完整相容模型。相容模式的光影與細節密度較低。

## 維護入口

| 檔案 | 責任 |
| --- | --- |
| `app/art-kit.js` | 共用尖拱窗、旗幟、星軌、燈籠、樹木、水晶、材質與六時段配色 |
| `app/world-art.js` | 七島與建築模型、可點選區域、入口座標及遠島細節 |
| `app/interior-art.js` | 美術館、圖書館、資訊工廠室內裝飾與展示台 |
| `app/scene-effects.js` | 環境光、陰影、選擇性輝光及雲霧 |
| `app/architecture-detail.js` | 窗格、石砌立面、簷口、屋頂瓦片、柱體與壁板的共用立體結構 |
| `app/batch-static.js` | 依材質、繪圖層次、投影／受影屬性合併靜態幾何 |
| `app/avatar-model.js` | 人物與實際穿戴的共用模型 |
| `app/astral.css` | 午夜藍、象牙白與金色介面，以及手機直式排版 |

島嶼與作品 ID、使用者資料、入口與橋樑導航均保留。配件仍以 `id` 保存收藏，以 `appearance` 選擇模型範本。六個時段繼續依臺北時間自動切換。

## 驗證界線

目前 54 項核心與美術館檢查與 TypeScript 檢查通過；主島專屬材質與模型另見 `HOME-ISLAND.md`。新增檢查覆蓋六時段酒紅色與布料摺面、凹窗實際深度、玻璃不參與泛光，以及合併後的燈光標記與失敗後材質還原。全場景頂點皆為有限值，作品與入口資料不變。

瀏覽器已再次載入主島、地圖、美術島與美術館室內，酒紅旗幟及新增立面可見，截圖見同目錄 `burgundy-museum-*-preview.jpg`。此瀏覽器的 WebGL 被停用，畫面採 SVG 相容繪圖。GPU 的選擇性輝光、實機陰影及手機效能尚未實測；相容模式截圖不是實機 GPU 光影證明。

科技島第二輪加入窄窗格、局部室內燈光紋理、深黑樓體與外環高架，詳見 `TECHNOLOGY-ISLAND.md`。其他島不套用科技窗光。

資訊工廠使用 `factory-kit.js`、`factory-island-art.js` 與 `factory-interior-art.js`，共用 `lib/factory-style.ts` 的室內家具範圍、室外碰撞與石階高度。暖光只照入口、吧台與座位，不提高全站曝光或暈光。

Information Factory 更新為純英文發光招牌、舊黑鐵板內外牆、菱紋壓花鋼板室內地坪與局部霓虹。新增 `factory-materials.js` 與 `factory-floor.js`；全站曝光與其他場景維持原值。

Information Factory 外景增加四段黑鐵維修梯、中繼平台、上層走道與 22 組安裝在梯段／平台上的暖黃護罩燈。原生局部外燈上限為六盞；其他場景曝光不變。
