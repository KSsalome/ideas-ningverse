# 手作礦島：暗黑哥德 × 蒸汽奇幻

依島主 2026-10-28 提供的礦山細節參考改善既有即時 Low Poly 3D 場景。修改限於礦島模型、材質與動畫；其他島嶼、網站 UI、導航、資料格式與互動路由保持原樣。

## 岩山與晶體

- 深灰岩石、黑色牆體、紫黑尖頂、深酒紅旗幟 `#4b1b2b` 與古銅金 `#9b754b`。六個臺北時段保留同一套礦島色系。
- 山體以不規則散點三角化形成偏心山脊、側峰及斜坡，取代固定高度的同心階梯。疊加 18 個大小、旋轉與高度不同的低面數凸岩塊，幾何仍位於既有半徑 7.8 的保留區內。
- 保留高 7.4 世界單位的山頂巨型緋紅水晶，基部嵌入山頂。尖塔、簇生、細針、薄刃與斷裂晶體共用五套低面數幾何，具有不同截面、肩部、長寬及傾斜角度。
- 晶簇從不規則岩面邊緣選取位置，並依實際岩面／岩塊三角形計算底部高度。晶體高度與粗細混合，避免沿固定等高線成排排列或浮在岩面上方。
- 原生材質共用兩張 4 × 32 像素的漸層貼圖：水晶依所在山坡高度選用深酒紅、寶石紅、亮緋紅與山頂紅四段色系，每顆晶體另有較暗基部與柔和的中心自發光。不使用自訂著色器或透明多層水晶；晶體本體不進入全域泛光，只有細晶脈與小核心保留局部光感。

## 高塔與礦洞

- 紫黑八角塔身、哥德尖拱、細尖塔、古銅月冠、三環星象儀與星圖地面保留。
- 六張雙面符文塔羅牌以不同高度、傾角與半徑環繞高塔，完整一圈約 140 秒。牌面淡紫符文、輕微上下浮動及最多 10 顆小型幾何光點形成魔法氛圍；SVG 相容模式減為四顆。
- 牌面固定幾何先合併，再以群組更新旋轉與位置。尊重減少動態效果設定，遠離礦島或礦島不顯示時停止動畫。
- 三個既有礦洞保留木造風格；依建築 ID 使用不同柱高、斜撐、樑傾角與簷頂，變化不影響入口。礦車、雙軌、枕木、貨箱及吊掛暖黃礦燈保留。
- 酒紅旗幟增加簡約古銅金月輪、分叉符文與菱形記號，以少量摺面及細線構成。
- 木平台、階梯、絞盤與吊掛礦車沿用。薄霧仍限局部山腳與島緣，透明度不超過 0.085。

## 效能與驗證

- 維持六盞有限距離點光源，距離不超過 6.2、強度不超過 18；離開礦島後停用。沒有提高全局曝光或泛光強度。
- 水晶、岩塊與小貼圖重用；靜態幾何依材質合併。預設完整礦島維持約 4.8 萬個三角形，遠景替身使用簡化山形與晶簇。這是幾何規模，並非實機幀率。
- 34 項核心測試通過：增加山體非對稱、有限邊界與向上表面、晶簇貼地、五種晶體、漸層與柔光限制、六張牌旋轉／減少動態效果／距離停用、三種木支架、粒子／幾何／燈光預算檢查。
- 原有入口尋路、橋樑、每日塔羅、三礦洞分類及施工資料檢查通過。其他六島材質、幾何和模型變換與修改前的雜湊一致。TypeScript 檢查通過。
- 瀏覽器已確認全景、礦洞作品集、每日塔羅入口及 390 × 844 直式預覽；手機文件寬度與 scrollWidth 同為 390。未抽取新牌或改寫作品。
- 預覽瀏覽器沒有 WebGL，使用 SVG 相容模式；原生 GPU 漸層、自發光、陰影與手機幀率仍待實際裝置確認。`mine-crystal-purple-glow-preview.jpg` 是最新相容模式構圖證明，不代表 GPU 光效。

## 2026-10-28：紫色牌光與山體高度色階

六張牌的外框與符文採獨立紫色發光材質，搭配每張牌一個低透明度柔光罩。原生模式使用共用 64 × 64 柔邊貼圖，不提高全場泛光。山頂巨晶使用獨立的自發光材質、淡紅光暈及局部紅光，保留深紅切面；塔羅塔的紫色局部照明和巨晶紅光共用原有六盞燈的額度。

水晶的山坡色階由實際岩面高度決定。原生模式以 UV 對應小型色階貼圖，沿用三種共用晶面材質；SVG 相容模式以少量共用分層材質呈現深淺。維持既有島嶼、山體、入口與角色路徑。34 項測試與型別檢查通過，含色階亮度、巨晶自發光及光暈透明度上限；原生 GPU 光效仍未實機測量。
