# 科技島：黑玻璃霓虹城

2026-10-27 依島主補充的三張城市夜景參考重製。採黑色量體、深色玻璃、交錯窗光、懸掛霓虹招牌與濕柏油倒影。參考照片未作為場景背景，未複製圖中的品牌、人物或車輛。

## 地面與反射

- 全島地面改為柏油；本機程序生成 256×256 顆粒色彩、法線與粗糙度貼圖。
- 粗糙度有局部差異，呈現乾濕不均的路面；車道虛線與路邊標記避開既有建築及中央地標。
- WebGL 採單一平面反射通道，直接映出當前場景中的物件與霓虹。桌面 512×512、手機 256×256，含模糊取樣、粗糙度遮罩與受限反射增益；路面不是整面高亮鏡子。
- 反射通道不參與輝光。輝光遮罩取代反射材質時，反射回呼會直接跳過；離開科技島附近時停用反射更新。
- 反射繪製暫時隱藏其他島嶼與遠景，並在 finally 中還原；採 Three.js Reflector 支援的正交反射相機。
- SVG 不支援即時反射，使用靜態色光倒影近似；這項近似不是 GPU 反射驗證。

## 建築與裝飾

樓體固定為深黑色 `#070b10`，金屬框架 `#1b2530`。窗戶採低粗糙度、有高光與環境反射的深色 Physical 玻璃材質；外牆玻璃不渲染未建置的室內。黃 `#ffda95`、淺藍 `#a9dfff`、淺紫 `#d4baff` 為主要窗光，少量紅 `#ff6b79` 點綴，並保留部分未亮窗戶。只有亮窗參與受限的局部光暈，未亮玻璃與牆體不參與。

窗光分布依建築 ID 決定，不因新增或刪除其他作品而重排。既有代表色資料不變，改用在燈帶與招牌；例如已保存的紅色玻璃外觀會呈現黑玻璃樓體與紅色燈帶／招牌。

加入直式燈箱、側向懸掛招牌、霓虹箭頭、數位看板、通風設備、排水管、遮雨棚與屋頂航空燈。招牌使用 TIME／DATA／LAB／PLAY／24H 等裝飾字，不在場景上方列出作品完整名稱；靠近建築時的底部名稱按鈕沿用。

中央地標改為黑色退台摩天樓、訊號看板、冷色燈帶與頂部天線。遊戲基地改為黑色雙翼遊戲館與玻璃入口，不沿用白色尖塔。

## 路燈

使用金屬長桿、曲臂、橫向燈具與下照式暖黃燈芯，含單臂與雙臂款式。科技島內及科技島端的橋頭路燈一致套用道路款式。地面有柔和光池；WebGL 使用最多 3 盞有限距離黃色聚光燈與 3 盞近距離霓虹補光，離開科技島後停用。

## 驗證界線

29 項核心測試覆蓋既有作品、導航、私人權限、六時段、收藏及主島；新增 17 種科技外觀／Schema ID 一致性、各款樓頂、玻璃材質、四種燈光、施工高度與自訂代表色，以及反射遮罩防重入、柏油貼圖、道路燈具與燈光範圍。

瀏覽器已驗證後台的黑玻璃外觀與 47% 施工預覽連動，以及新建遊戲帳號自動切至科技島和遊戲基地。測試採本機臨時頁且未保存，臨時頁在正式建置前移除。

以修改前提交 `46fc75eb8a8e6bd36adefb347a7fc66acd94dabe` 對照主島、礦作、美術、圖書、社交、資訊六島，材質類型／顏色、模型尺寸／旋轉／位置與全部三角形座標雜湊一致。橋頭採科技道路燈的部分另依新規格更新。

預覽瀏覽器沒有 WebGL，實際使用 SVG 相容模式。實機平面反射、玻璃高光、聚光燈及手機效能尚未測量；不把相容模式截圖視為 GPU 光影實測。


## 第二輪：細窗格與高架都市層次

- 樓體由 `#10151c` 加深到 `#070b10`，金屬窗框改為深色細框。每個立面約 5–10 欄，樓層節距約 0.68；單格寬度低於 0.48、高度低於 0.57 世界單位。後台與作品頁共用窗格規則和色票。
- 玻璃維持物理反射材質，亮窗新增室內漸層、百葉陰影與隔間紋理。夜間發光強度 1.25、日間 0.75；只有亮窗、招牌與燈芯可進入既有的局部光暈，全局曝光／光暈強度維持不變。未亮玻璃與黑色牆面不發光。
- 科技島外圈增加雙向環狀高架，包含連續柏油橋面、混凝土梁與橋墩、懸臂支承、分隔線、邊線、金屬護欄、反光標、路標架和 12 組黃光道路燈。高架為環境景觀，目前未新增駕駛或高架步行模式；既有跨島橋仍在下方通行。
- 地面增加外環道路、交錯幹道、通往各建築入口與三個橋頭的支路、行人穿越線、路緣、排水溝和人孔蓋。支路使用同一套步行尋路結果；若新增建築佔用原本起點，會重新選擇合法道路起點。
- 周界與建築後側加入密集金屬柵欄，橋頭及主要步行路線保留空隙。模型在既有靜態批次合併中處理；玻璃小窗改用共用平面幾何，每格 2 個三角形，降低細分後的幾何成本。遠景仍保留高架輪廓。

驗證新增窄窗尺寸、室內燈光貼圖、夜／日亮度、全局曝光上限、高架面朝向、跨島橋下方淨高大於 2.9、道路可走、柵欄避開保留路線，以及動態建築配置。實機 WebGL 光暈、反射與手機效能仍未測量。
