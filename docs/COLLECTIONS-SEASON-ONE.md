# 第一季：漂流瓶收藏與旅人換裝

原有 11 件瓶中收藏與每日羽毛保持原 ID，第一季另加 12 件 `s1-*` 珍藏。基礎圖鑑因此有 24 件；畫面總數、已獲得數與第一季進度均由實際資料計算，也會包含島主後續新增的收藏。

## 四階段交付與檢查

1. 資料與圖鑑：新增來源、普通／稀有／史詩／傳說、季別與季內編號；先驗證資料合併及舊收藏身份，再擴充既有卡片。保存的名稱、說明、顏色、停用及封存設定優先於預設值。
2. 基本換裝：沿用既有圖鑑排版、分類與旋轉預覽；加入六個獨立裝備位置，驗證所有新物品的實際幾何、持久保存、卸下與替換。舊 `prop` 胸飾在讀取時移至胸腰欄位，庫存及羽毛日期不會被重寫。
3. 漂流瓶：原有附近拾取操作、生成時間、每人最多兩瓶及有效期保留；依旅人當前島嶼生成可步行接近的瓶子，優先選擇未收藏的該島主題物品，其次為尚未收藏的舊瓶中收藏。D1 原子批次處理挑選、入庫與領取，驗證重複點擊及同時開啟不同瓶子的情境。
4. 特殊裝備與效能：完成六時序內襯、霓城青藍燈帶及漂浮塔羅牌；驗證減少動態效果設定、低面數、零新增燈光／粒子、窄螢幕分類和預覽旋轉。

## 資料保存與相容

沿用 `inventory`、`wardrobes`、`reward_catalog` 及 `pet_feathers`，沒有資料表重建或破壞性遷移。舊資訊、取得時間、每日羽毛、已封存收藏均保留。六個欄位存於原 wardrobe JSON；手持欄位仍使用 `prop` 鍵以相容既有手杖、手札與提燈。

裝備 API 驗證目前訪客／帳號的所有權及物品所屬位置，未獲得或放錯欄位會被拒絕。局部更新保留其他欄位；新物品入庫不自動穿戴。舊胸飾改放胸腰欄位後，可以與手持物同時穿戴，同一欄位僅保留一件。

未解鎖第一季物品只在介面顯示季內編號、剪影與簡短探索提示；解鎖後展示名稱、圖示、故事、來源、稀有度及裝備按鈕。稀有度不增加能力，也不建立付費機率或貨幣。

## 場景與效能

室外旅人、圖書館、美術館、資訊工廠與角色預覽共用同一組角色／裝備模型。裝備更新沿用角色當前位置及面向，不重建島嶼。島嶼幾何、道路、橋樑、入口、移動速度和碰撞計算沒有更動。

使用簡單幾何與頂點色製作雙色髮，不載入外部模型。塔羅牌僅有慢速浮動、轉角及一張 32×32 柔光貼圖；霓城外套使用 emissive 材質，沒有新增實際燈光或粒子系統。特殊效果可隨減少動態效果設定靜止。SVG 相容模式保留配戴外觀，停用持續漂浮與柔光貼圖，延續按需重繪。

預覽只有裝備塔羅牌且畫面可見時才啟用最多 24fps 的動畫，切到背景或滾出畫面即停下。原有手機解析度、30fps 目標、陰影與反射預算保持不變。這些是程式設定，並非手機實際 FPS 測量。

## 驗證證據

- 93 項場景、導航、時間切換、效能及收藏單元測試通過；雙色髮及柔光最後調整後，重跑相關 5 項角色／收藏測試通過。
- TypeScript 型別檢查通過。
- 獨立 Miniflare/D1 的完整 API 整合測試通過，涵蓋 12 件取得、六欄穿戴保存、卸下、未解鎖拒絕、跨帳號隔離、原子領取、重複領取、各島生成與舊資料保留。
- 瀏覽器使用實際元件檢查：開瓶提示、未自動穿戴、圖鑑數量更新、六欄同時穿戴、旋轉、同位置替換、重新整理及 390px iframe 版面。
- 首頁背包由實際 API 成功讀取 24 件基礎圖鑑；預覽缺少的測試用 SESSION_SECRET 僅補於被 Git 忽略的本機設定，正式環境設定未變動。
- 可用雲端瀏覽器不支援 WebGL，視覺檢查為 SVG 相容模式；實機手機 FPS 與原生 WebGL 發光效果仍需裝置檢查。

`collections-wardrobe-preview.jpg` 與 `collections-mobile-preview.jpg` 是使用獨立測試收藏的實際瀏覽器畫面，並非替玩家解鎖物品。`collections-integrated-preview.jpg` 是首頁實際 API 載入後的圖鑑。測試頁在發佈前移除，正式行囊不提供測試解鎖入口。
